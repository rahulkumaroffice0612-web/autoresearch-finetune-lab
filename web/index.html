▶ Try it yourself

Run the real model on your own invoice — a local Gradio playground with sliders for invoice total, PO total, quantities, due dates and vendor history. Three commands on a Mac (Apple-Silicon MLX build):

git clone https://github.com/rahulkumaroffice0612-web/autoresearch-finetune-lab
cd autoresearch-finetune-lab
uv venv --python 3.12 .venv && uv pip install --python .venv/bin/python unsloth gradio
.venv/bin/python src/playground.py            # opens http://127.0.0.1:7860
# add --share for a temporary public link

The "can't cheat" part

  • 🔒 Sealed test — only its SHA-256 is committed; the worker literally can't read the cases.
  • 📏 Official scorer — copies the dataset's grading arithmetic verbatim.
  • 💸 Tinker spend cap in code — the free local loop strips TINKER_* from its env.
  • 🧊 Config frozen first — every finalist is committed to git before its one-shot sealed read.
